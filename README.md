After cloning this repository, create a.env file at the project root from .env.example (cp .env.example .env).

Environment variable to set:
Variable: VITE_API_URL;
Description: Base URL of the backend API;
Example: http://localhost:3000/api

Run the project with npm run dev. The app is then available at http://localhost:5173 (Vite's default port).
